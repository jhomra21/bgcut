# bgcut documentation

- [`engineering/graph-capture.md`](engineering/graph-capture.md): browser graph-capture design, correctness checks, and accepted measurements.
- [`engineering/roadmap.md`](engineering/roadmap.md): planned engine, compatibility, and editor work that is not part of the current public contract.

## Operations

- [`operations/deploying.md`](operations/deploying.md): Cloudflare Workers, R2, local smoke checks, and production deployment.
- [`operations/releasing.md`](operations/releasing.md): npm Trusted Publishing, beta acceptance, and stable release procedure.

Public package usage belongs in the root [`README.md`](../README.md). Release history stays in [`CHANGELOG.md`](../CHANGELOG.md). Repository rules stay in [`AGENTS.md`](../AGENTS.md).
