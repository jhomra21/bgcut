# SEO competitor watch

This list tracks products and publishers that compete with bgcut for search intent. It is not a product ranking.

Recheck the dated source before copying any external fact into a comparison page.

## Search/content competitors

- AlternativeTo for remove.bg alternative lists.

## Weekly review

For each competitor, record only meaningful changes:

- new pages targeting one of the watched clusters;
- new or removed product interfaces;
- pricing or usage-model changes that affect an existing comparison;
- newly documented privacy or deployment behavior;
- new benchmark or performance claims worth reproducing independently;
- new backlinks, directories, or roundup pages that could also be relevant to bgcut.

Do not copy a competitor's framing automatically. A new page is a signal to inspect the query, not proof that bgcut needs a matching page.

## Search gain data

Use Search Console for bgcut's own query movement. Use a connected SEO data provider for estimated competitor keyword/ranking changes if needed.

Keep provider estimates labeled as estimates. Do not merge them with first-party Search Console observations.
