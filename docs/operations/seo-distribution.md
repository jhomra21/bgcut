# SEO distribution and outreach

Use this after a page or tool is live and its claims have passed the normal product checks.

## Directory targets

Prioritize places where bgcut naturally belongs rather than bulk-submitting to generic SEO directories.

| Target | Fit | Submission angle |
| --- | --- | --- |
| AlternativeTo | High | Open-source/local alternative to remove.bg; browser, CLI, and Node.js are distinct from hosted-only tools |
| Product Hunt | High for a release or major milestone | Local background removal across browser, CLI, and Node.js, with no source-image upload to bgcut |
| GitHub topics and repository discovery | High | background-removal, local-ai, webgpu, onnx, nodejs, cli, privacy |
| npm package discovery | High | Node.js background removal, local inference, CLI, WebGPU/CPU |
| Awesome/self-hosted or privacy-focused lists | Conditional | Submit only when the list accepts local developer tools that match its stated scope |
| JavaScript/Node package roundups | Conditional | Node object API, removeMany, local runtime |
| Privacy/local-first tool directories | Conditional | Browser inference plus inspectable open source implementation |

Avoid directories whose only value is a followed link or that require misleading categories.

## Outreach angles

Limit outreach to a small number of sites where a new bgcut page adds something their current article is missing.

Useful pitches:

- remove.bg migration coverage that discusses hosted successors but omits local JavaScript/Node options;
- Node.js background-removal articles that only list hosted APIs;
- privacy/background-removal articles that do not distinguish local inference from ordinary asset downloads;
- open-source background-removal roundups missing a JavaScript CLI and Node option;
- WebGPU local-AI articles that could use a small real product example.

Every pitch should link to the most relevant page, not always the homepage.

## Outreach record

For each pitch record:

- site and author;
- article URL;
- why bgcut is relevant to that exact article;
- destination bgcut page;
- date sent;
- reply;
- resulting link or update.

Do not send the same generic pitch to multiple writers. Five relevant pitches are better than fifty unrelated submissions.
